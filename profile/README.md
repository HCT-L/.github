## About HCT-L

**HCT-L (Home Control Technology)** develops ideas, hardware and software for practical home and building automation. Our goal is to make intelligent control flexible, understandable and suitable for real installations.

## Meet MeshMaster

**MeshMaster** is our modular home automation project. It brings together connected devices, local control and a unified user interface with the goal of making everyday building functions easier to manage.

### What we're working toward

| Area | Goal |
| --- | --- |
| 💡 **Lighting** | Convenient switching, schedules and intelligent automation |
| 🪟 **Shutters & blinds** | Flexible control of compatible motorized shutters and blinds |
| 🚪 **Gates & entrances** | Integration with compatible gate and entrance controllers |
| 📡 **Wireless networking** | A cooperative mesh of connected modules |
| 🧩 **Modular hardware** | Purpose-built input, output and control modules |
| 📱 **Unified app** | Configuration, visualization and daily control |
| ⏱️ **Automation** | Customizable control functions and timed actions |

## Our principles

- **Local-first:** prioritize local operation rather than dependence on external services.
- **Modular by design:** develop a platform that can grow with new needs.
- **Practical and reliable:** focus on useful, everyday functions.
- **Clear user experience:** make complex automation accessible.
- **Integrated development:** evolve hardware, firmware and software as one system.

## Development status

MeshMaster is an **active development project**. The features described here express the platform's goals and development direction; they should not all be interpreted as finished or commercially available products.

Our source code, internal technical documentation and hardware design files are maintained in **private repositories**. This page intentionally shares only public, high-level information about HCT-L and MeshMaster.
